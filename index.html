WalkieTalkie · secure voice bridge for Claude Desktop

Speak on mobile.
Inject on desktop.
Hear Claude reply back.

WalkieTalkie is a production-focused, cross-platform voice bridge that captures speech on a mobile device, encrypts it end-to-end, transcribes locally on desktop, applies a risk filter, injects the transcript into Claude Desktop, and streams the reply back sentence-by-sentence as speech.

Overview

What it does

  • Mobile push-to-talk captures PCM16 mono audio.
  • Desktop decrypts audio and transcribes locally.
  • Risk filter flags potentially destructive instructions for confirmation.
  • Approved text is injected into the active Claude Desktop composer.
  • Claude responses are streamed back as live speech.

Quick start

How to use

  1. Start the desktop agent and grant Accessibility permission on macOS if needed.
  2. Open the mobile app and scan the pairing QR.
  3. Hold the mic button to speak; release to flush the last chunk.
  4. Watch the transcript appear in Claude Desktop and listen for reply streaming.
Desktop: walkietalkie-agent
Mobile: flutter run
Validation

Automated smoke testing

Use the repository harness to verify pairing, encrypted transport, mock STT, risk filtering, and injection wiring: 

python3 scripts/smoke_harness.py

This is fast, deterministic, and does not require a real mobile device.

System design

Architecture

  • Mobile: QR pairing, X25519 key generation, AES-GCM audio packets, push-to-talk capture.
  • Desktop: WebSocket ingress, session validation, local transcription, risk checks, injection, reply capture.
  • Security: encrypted transport, short-lived session tokens, no cloud STT dependency.
  • Observability: structured logging and local audit logs.
Setup

Setup notes

  • Environment variables use the WALKIETALKIE_ prefix.
  • Set WALKIETALKIE_DESKTOP_TARGET to claude, chatgpt, codex, or cursor.
  • macOS injection and response capture require Accessibility permission.
  • Faster-Whisper runs locally on the desktop.
